MIT 8103 Advanced Database Systems Portfolio
Favour Okoh | Student ID 301930463

Case study: VaxTrace NG, a fictional regional vaccine inventory and cold-chain network. All records are synthetic.

Private GitHub repository:
https://github.com/Favourz1/mit8103-vaxtrace-ng

Portfolio contents
1. Database design and modelling: ER model, PostgreSQL schema, seed and integrity checks.
2. Query processing and optimisation: SQL reports, results, execution plans and measured comparison.
3. Transactions and concurrency: transfer operations, rollback, invalid-case checks and two-session test.
4. NoSQL document model: MongoDB equipment, readings, exposure windows and verified queries.
5. Distributed database exercise: PostgreSQL streaming standby, read-only checks and controlled lag.

The three-page portfolio summary describes the five activities, evidence, design choices and references. The source archive preserves the runnable repository structure. Each portfolio folder contains a README with setup commands and a description of its saved evidence. The root README explains the PostgreSQL rebuild and verification command.

PostgreSQL 18.6, MongoDB 9.0.4 and Python 3.11 were used for the local tests. Local database files, passwords and credentials are excluded from the portfolio.
